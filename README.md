# Himanshu Portfolio

A personal portfolio website for Himanshu, showcasing skills, experience, projects, certifications, and contact information.

## Project Overview

- Static portfolio built with HTML, CSS, and JavaScript
- Responsive design optimized for desktop and mobile
- Animated hero section, skill bar animations, mobile navigation, and contact form integration
- Contact form submission via Web3Forms API

## Features

- Smooth scrolling navigation
- Mobile-friendly menu
- Animated skill bars using IntersectionObserver
- Project showcase cards
- Contact form with validation and submission feedback

## Files

- `index.html` — main portfolio page
- `style.css` — responsive styling and layout
- `script.js` — interactive behavior and form handling
- `himanshu.pdf` — downloadable resume

## Local Setup

1. Open the project folder in your editor or browser.
2. Open `index.html` in the browser to view the portfolio.
3. No build step is required.
